# Hardware

PCB, wiring and CAD files will go here. Suggested layout:

```
hardware/
  pcb/       KiCad / EasyEDA project, gerbers, BOM
  wiring/    wiring diagrams (relays, motor, pump, sensors, power)
  cad/       enclosure and ramp mechanism models
```

Until then, the pin assignments and wiring facts the firmware depends on are listed in `docs/DEVELOPMENT.md`
("Hardware facts the code depends on").
