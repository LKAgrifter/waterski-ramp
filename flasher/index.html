Keep settings? The installer may offer to erase the device. Leave that unticked when updating a board: erasing wipes saved settings (a remote's ID, the ramp's last height). Tick it only for a brand-new board or if a board misbehaves.

Steps

  1. Type the bind phrase (the same one for the ramp and all its remotes).
  2. Plug the Heltec board into this computer with a USB-C data cable.
  3. Click the install button for the board you're flashing, pick the board's port, and confirm.
  4. Wait for it to finish (about a minute), then unplug it.
  5. New remote: on the remote, hold MENU to reach the NETWORK page, then hold UP and DOWN together for 2 seconds to change its ID. Each remote talking to the same ramp needs a different ID (1–4).
  6. Flash the ramp and all remotes from the same version and the same bind phrase. Boards on older (unencrypted) firmware can't talk to this version: their NETWORK page counts them as "Old firmware heard".
  7. Check every board's NETWORK page shows the same Bind: code. A board that hears another with a different phrase counts it as "Bad key".

If it doesn't connect

  • Try another cable (many USB-C cables are charge-only) or another USB port.
  • Hold the board's PRG button while plugging it in, then try again.
  • Close the Arduino IDE or anything else that might have the port open.
