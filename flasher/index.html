Ramp controller

For the board in the ramp. Disconnect motor and pump power before flashing.

Type a bind phrase above first.

Use Chrome or Edge on a computer to flash. This page must be opened over https.
This flasher never erases the board. Erasing would delete the board's Heltec radio license (each board keeps it in its flash; without it the firmware stops at start-up and the screen stays off), as well as its saved settings. So installing only writes the firmware: settings like the ramp's last height and the motor counters are kept. Don't use other tools' "erase flash" option on these boards either.

Steps

  1. Type the bind phrase (the same one for the ramp and all its remotes).
  2. Plug the Heltec board into this computer with a USB-C data cable.
  3. Click the install button for the board you're flashing, pick the board's port, and confirm.
  4. Wait for it to finish (about a minute), then unplug it.
  5. Remotes: each remote talking to the same ramp needs a different ID (1–4): pick it, and the type (Boat or Shore), before flashing. The remote takes them on its first start after flashing. You can change them later on the remote: NETWORK page (ID) and WATER page (type), hold UP and DOWN together for 2 seconds.
  6. Flash the ramp and all remotes from the same version and the same bind phrase. Boards on older (unencrypted) firmware can't talk to this version: their NETWORK page counts them as "Old firmware heard".
  7. Check every board's NETWORK page shows the same Bind: code. A board that hears another with a different phrase counts it as "Bad key".

If it doesn't connect

  • Try another cable (many USB-C cables are charge-only) or another USB port.
  • Hold the board's PRG button while plugging it in, then try again.
  • Close the Arduino IDE or anything else that might have the port open.

If the screen stays off after flashing

Check the board's messages: Arduino IDE > Tools > Serial Monitor at 115200 baud (or the installer's Logs & Console). If it repeats Please provide a correct license! and an ESP32ChipID=, the board's Heltec license was erased:

  1. Look up that chip ID at resource.heltec.cn/search. You get four numbers like 0x1A2B3C4D,0x....
  2. In the Serial Monitor (line ending "Both NL & CR"), send AT+CDKEY= followed by the four numbers without the 0x and commas (32 characters).
  3. It answers The board is actived and starts. The license stays on the board from then on.
