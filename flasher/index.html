Ramp firmware flasher

Install the ramp controller or remote firmware straight from this page. No Arduino IDE, drivers or downloads.

Remote

For a handheld remote. One file works for every remote: set each remote's ID on the remote afterwards.

Use Chrome or Edge on a computer to flash. This page must be opened over https.

Ramp controller

For the board in the ramp. Disconnect motor and pump power before flashing.

Use Chrome or Edge on a computer to flash. This page must be opened over https.
Keep settings? The installer may offer to erase the device. Leave that unticked when updating a board: erasing wipes saved settings (a remote's ID, the ramp's last height). Tick it only for a brand-new board or if a board misbehaves.

Steps

  1. Plug the Heltec board into this computer with a USB-C data cable.
  2. Click the install button for the board you're flashing, pick the board's port, and confirm.
  3. Wait for it to finish (about a minute), then unplug it.
  4. New remote: on the remote, hold MENU to reach the NETWORK page, then hold UP and DOWN together for 2 seconds to change its ID. Each remote talking to the same ramp needs a different ID (1–4).
  5. Flash the ramp and all remotes from the same version; they share a radio message format.

If it doesn't connect

  • Try another cable (many USB-C cables are charge-only) or another USB port.
  • Hold the board's PRG button while plugging it in, then try again.
  • Close the Arduino IDE or anything else that might have the port open.
